# 03 — Personality (Companion)

**Główny wzorzec:** Hello Minds (Soul, always-on, skills jako playbooki, proaktywność, kumulująca się pamięć relacji).  
**Technika formatu:** SillyTavern (karta postaci + World Info).

`personality/base.md` powinien zawierać:
- Description (kim jest, styl, granice)
- Personality (krótkie cechy)
- Scenario / styl współpracy
- Example dialogues (`mes_example`)
- Granice i zasady
- Możliwość rozbudowy (lorebook-like, user facts)

Cel: prawdziwy współpracownik, nie wykonawca poleceń.  
Pamięta relację, dyskutuje pomysły, przychodzi z własnymi odkryciami, uczy się.

## Reverse-engineering mandate
Rozbierz najpierw:
- Hello Minds (Soul, Skills, Circles, jak pamięć i proaktywność tworzą companion).
- SillyTavern character card format (description, personality, scenario, first_mes, mes_example, character_book) — jako technikę trzymania osobowości.
Zbuduj własny format deklaratywny w Markdown/YAML.
